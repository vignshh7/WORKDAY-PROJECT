CORE PRINCIPLES
- Supabase PostgreSQL is the source of truth.
- Spring Boot enforces authentication, authorization, business rules,
  scheduling constraints, transactions and state transitions.
- Agentic AI interprets natural language, orchestrates tools, ranks valid
  options and explains decisions.
- AI must NEVER directly access SQL/PostgreSQL.
- AI must NEVER invent availability, interviewer skills or booking success.
- Frontend is not the source of truth.
- Use Java 21, Spring Boot 3.x, Maven, Spring Web, JPA/Hibernate,
  Spring Security/JWT, BCrypt, Validation, PostgreSQL, Flyway, Lombok,
  Actuator and OpenAPI/Swagger.
- Use a modular monolith. Do not introduce microservices, Kafka, Redis,
  Kubernetes or a Python agent server.
- Use constructor injection, DTOs, services and repositories.
- Use spring.jpa.hibernate.ddl-auto=validate. Flyway is the schema source of truth.
- Never hardcode secrets.

FINAL DESIGN STATEMENT:

The system is NOT:
LLM -> Database -> Booking

The system IS:
LLM -> Controlled Tools -> Spring Boot Services
    -> deterministic validation -> Supabase PostgreSQL/external integrations

PostgreSQL stores facts.
Spring Boot enforces rules.
AI orchestrates and explains.
React provides the user experience.
